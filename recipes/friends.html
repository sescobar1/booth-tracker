Make your own Family Cookbook

A free recipe website for your family. Snap photos of recipe cards, and everyone you share it with can read, add and fix recipes.

🍳 The short version

One-time setup, about 30 minutes. A computer makes it much easier than a phone.

  1. Download the kit (button below) and unzip it.
  2. GitHub: make a free account and upload the kit. This becomes your website.
  3. Supabase: make a free account and paste in setup.sql. This is where your recipes and photos are saved.
  4. Connect them: copy 2 codes from Supabase into config.js on GitHub.
  5. Turn on family photos: paste one small file into Supabase.
  6. Open your cookbook, sign in, add recipes, and tap Send link to share with family.
⬇ Download the cookbook kit

Every step is explained below, with the exact buttons to press.

Step 1 Download the kit

  1. Tap Download the cookbook kit above. You get a file called cookbook-kit.zip.
  2. Unzip it: on Windows, right-click it and choose Extract All. On a Mac, double-click it.
  3. You now have a cookbook-kit folder. Inside are files like index.html, config.js, setup.sql and a few folders. Keep it handy.

Step 2 GitHub: your website

GitHub holds the cookbook's pages and gives you a free web address.

Make your account

  1. Go to github.com/signup.
  2. Type your email, make a password, and pick a username. Your username becomes part of your web address. For example, janesmith gets janesmith.github.io.
  3. Do the puzzle check, then type the code GitHub emails you.
  4. If it asks questions about how you'll use GitHub, you can skip them.

Put the cookbook on it

  1. Click the + at the top right, then New repository. A repository is just a folder for a project.
  2. For Repository name, type cookbook.
  3. Choose Public. The free website needs this. Only the app's code is public: your recipes are saved in Supabase, not here.
  4. Click Create repository.
  5. On the next page, click the link uploading an existing file.
  6. Open your cookbook-kit folder. Select everything inside it (Ctrl+A on Windows, Cmd+A on a Mac) and drag it all onto the GitHub page.
  7. Wait until every file is listed, including vendor/supabase.js. Then click Commit changes at the bottom.
Drag the files inside the folder, not the folder itself. index.html must be at the top level of your repository, not inside another folder.

Turn on the website

  1. In your repository, click Settings (top row), then Pages (left side).
  2. Under Branch, choose main and / (root), then click Save.
  3. Wait 1–2 minutes and refresh the page. It shows “Your site is live at …” with your address, like https://janesmith.github.io/cookbook/. That's your cookbook!
  4. If you open it now, it says “Almost ready!”. That's normal; Steps 3 and 4 finish it.

Step 3 Supabase: where recipes are saved

Make your account and project

  1. Go to supabase.com/dashboard. Click Continue with GitHub to use the account you just made.
  2. Click New project. Keep the free plan.
  3. Project name: cookbook. Database password: click Generate a password and save it somewhere safe. You won't need it often. Region: pick the one closest to you.
  4. Click Create new project. It takes about 2 minutes to get ready.

Paste in the setup

  1. In the left menu, click SQL Editor. If you don't see a blank box, click + New query.
  2. In your cookbook-kit folder, open setup.sql: Notepad on Windows (right-click → Open with), TextEdit on a Mac.
  3. Select all of it, copy it, and paste it into the Supabase box.
  4. Click Run. It should say Success. No rows returned.
If Supabase warns that the query has “destructive operations”, click to run it anyway. It's only replacing old copies of its own rules, so it's safe to run more than once.

Make your sign-in

  1. In the left menu, click Authentication, then Users.
  2. Click Add user → Create new user.
  3. Type your email and a password you'll remember. Leave Auto Confirm User checked. Click Create user.

This is the only account that can sign in. Your family never needs one; they use the link you send them.

Step 4 Connect GitHub to Supabase

Copy 2 codes from Supabase

  1. Click the gear, Project Settings, at the bottom of the left menu.
  2. Click Data API (or API) and copy the Project URL. It looks like https://abcdefgh.supabase.co.
  3. Click API Keys and copy the anon public key. It's a long code starting with eyJ. If you see tabs, it's under Legacy API Keys. A key starting with sb_publishable_ also works.
Don't use the key marked secret or service_role. That one must never go on your website.

Paste them into config.js

  1. Go back to your cookbook repository on GitHub and click the file config.js.
  2. Click the pencil ✏️ (Edit) at the top right of the file.
  3. Replace PASTE_YOUR_PROJECT_URL_HERE with your Project URL, and PASTE_YOUR_ANON_KEY_HERE with your key. Keep the ' quote marks around each one.
  4. If you like, change 'Me' to your first name and change the footer line.
  5. Click Commit changes, then Commit changes again.

Wait a minute, then open your cookbook address. Sign in with the email and password from Step 3. 🎉

Step 5 Let family add photos

This small piece lets family upload photos without having their own sign-in.

  1. In Supabase, click Edge Functions in the left menu.
  2. Click Deploy a new function → Via Editor.
  3. Name it exactly recipe-upload.
  4. Delete the sample code. Open supabase-functions/recipe-upload.ts from your kit, copy all of it, and paste it in.
  5. Click Deploy function.
  6. Open the function's Details (or settings) and turn off Enforce JWT verification (it may be called Verify JWT). Save. The function checks the family link itself.

If you skip this, family can still add and edit recipes, just not upload photos.

Optional ✨ “Type it out for me” that reads handwriting

The cookbook can type out a recipe card from its photo. Without this step, it uses a free reader on the phone. That reader works on printed recipes but often misreads handwriting. The smarter reader costs a few cents per card.

  1. Make an account at console.anthropic.com, add a little credit, and create an API key.
  2. In Supabase, go to Edge Functions → Secrets. Add a secret named ANTHROPIC_API_KEY with your key as the value.
  3. Deploy a second function the same way as Step 5, named recipe-read, using supabase-functions/recipe-read.ts. Leave JWT verification on for this one, so only you can use it.

Step 6 Use it and share it

  1. Tap ＋ Add a recipe, take a photo of a recipe card, and tap ✨ Type it out for me. Check it over, then Save recipe.
  2. On a recipe, tap 📷 Add a photo of this dish to upload, paste, or find a picture of the food.
  3. To share: in the Share with family box at the top, tap Send link.
  4. Anyone with the link can read, add, edit and delete recipes. They don't need an account. Deleted recipes go to 🗑 Recently deleted, where you can bring them back.
  5. Put it on your Home Screen. iPhone: in Safari, tap Share → Add to Home Screen. Android: in Chrome, tap ⋮ → Add to Home screen.
Only send the family link to people you trust, since they can change recipes.

If something's not right

It says “Almost ready!”The codes in config.js aren't pasted yet, or GitHub hasn't updated. Check Step 4 and wait a minute.
GitHub shows a 404 pageWait a few minutes after turning on Pages. Also make sure index.html is at the top of the repository, not inside a folder.
“Invalid login credentials”Check the email and password from Step 3. You can delete that user and make it again with Auto Confirm User checked.
Errors about missing tablesRun setup.sql again (Step 3).
Family can't add photosDo Step 5, and make sure JWT verification is off for recipe-upload.
It stopped loading after a quiet weekFree Supabase projects pause after about a week with no visits. Sign in at supabase.com and click Restore project.

Everything here is free: GitHub Pages hosts the website, and Supabase's free plan stores the recipes and photos. Only the optional smart reader costs anything.
